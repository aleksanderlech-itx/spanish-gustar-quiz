The gold badge that names a level (A1, A2, B1) or a progress count on a tile. Badges name difficulty or progress. They never signal an error.

- Level badge: `sun` fill, `sun-ink` text in the `badge` style, `radius-segment` corners, 4px 10px padding.
- Tile pills: 11px bold on `radius-pill`. Use progress (`sun`), due (`clay-soft` with `muted`) or today-done (`sage-soft` with `sage`).
- **Consumer provides:** the short label text.
