A quiet surface button for the alternative path: Skip, Back to topics, Practice options. Use it next to a PrimaryAction, or alone when no single action dominates.

- `surface` fill, `border-ink` 1px outline, `ink` label in the `action` style, `radius-control`, at least 48px tall.
- Skip never scores an answer.
- **Consumer provides:** the label and the handler or href.
